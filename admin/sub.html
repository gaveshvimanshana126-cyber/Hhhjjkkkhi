Subtitle Cleaner

Upload an .srt file, list the words you want gone, and every subtitle block that contains one gets removed — timestamps and numbering renumbered automatically.

Runs entirely in your browser

Your subtitle file is never uploaded anywhere — everything below happens locally on this page.

1. Upload your .srt file(s)

Drag and drop one or more files, or click to browse. Every file is cleaned with the same keyword list and credit settings below.

2. Blacklist words

Any subtitle block containing one of these (case-insensitive) will be removed. Add or remove as needed — the defaults below are common ad/watermark lines.

3. Credit text (optional)

When enabled, this text is inserted as its own subtitle block: before the first line, in any silent gap longer than 60 seconds, and for 60 seconds after the last line.

4. Process

Removes matching blocks, inserts credit text if enabled, and renumbers everything so each .srt stays valid.
